GitHub Gist Sync

Verilerinizi özel bir GitHub Gist'te saklayın. Bilgisayar, tablet veya telefondan erişin.

Nasıl Kullanılır?

1. github.com → Settings → Tokens adresinden "gist" yetkili bir PAT oluşturun.

2. Token'ı yukarıya yapıştırın ve Yükle'ye basın. İlk seferde otomatik Gist oluşturulur, ID kaydedilir.

3. Başka bir cihazda aynı token'ı girin, Gist ID'yi de ekleyin ve İndir'e basın.

Not: Token bu cihazda localStorage'da saklanır. Kişisel cihazınızda kullanın.
